<h2>ストーリー1: コンゴ民主共和国でエボラ治療の大規模試験</h2>
<ul>
<li>The Guardianは7月12日、コンゴ民主共和国で「記録的規模」とされるエボラ治療試験に最初の患者が登録されたと報じた。感染症流行時の治療選択肢と臨床研究の基盤に関わる動きである</li>
<li>NHK・朝日・毎日・産経・読売・日経の当日取得記事には、この試験を扱う見出しは確認できなかった</li>
<li>日本の国際報道では、アフリカの保健医療は大流行や日本人被害の局面で注目されやすく、治療研究の開始段階は継続的に追われにくい</li>
</ul>
<h2>ストーリー2: ナイジェリア軍「武装集団300人殺害」</h2>
<ul>
<li>The Guardianは7月11日、ナイジェリア政府が北西部ザムファラ州で軍が武装集団300人を殺害したと発表した件を報じた</li>
<li>同国では治安悪化、誘拐、住民避難が長期課題となっている。発表の規模が大きい一方、日本6媒体の当日取得記事には該当する見出しがなかった</li>
<li>アフリカの治安ニュースは、政変や大規模テロ以外では日本の主要媒体の国際面に入りにくいという偏りが表れている</li>
</ul>
<h2>ストーリー3: 途上国の対外債務返済、教育支出を上回る</h2>
<ul>
<li>The Guardianは国連の新たな集計として、途上国が外国債務の返済に使う額が教育支出を上回っていると報じた</li>
<li>これは教育、人材育成、貧困対策を圧迫する構造問題であり、単発の市場ニュースでは見えにくい国際経済の論点である</li>
<li>NHK・朝日・毎日・産経・読売・日経の当日取得記事では、この国連集計や債務と教育支出の逆転を伝える見出しは確認できなかった</li>
</ul>
<h2>ストーリー4: 南アフリカ、移民取締りで5万3000人超を送還</h2>
<ul>
<li>BBCは、南アフリカ政府が移民取締りのキャンペーンで外国人5万3000人超を送還したと発表したことを報じた</li>
<li>移民政策、人権、周辺国との関係にまたがる問題だが、日本6媒体の当日取得記事にはこの規模の送還作戦を扱う見出しが見当たらない</li>
<li>欧州や米国の移民政策は報じられやすい一方、アフリカ域内の移動と取締りは日本語のニュース選択からこぼれやすい</li>
</ul>
<h2>ストーリー5: パリ近郊のシナゴーグ周辺で武器発見、数百人避難</h2>
<ul>
<li>France24は7月12日、パリ近郊でシナゴーグ近くに武器が見つかり、数百人が避難したと報じた</li>
<li>フランスでは反ユダヤ主義への警戒が政治・治安両面の課題になっており、この事案も宗教施設の安全をめぐるニュースとして位置づく</li>
<li>NHK・朝日・毎日・産経・読売・日経の当日取得記事に、この避難事案の見出しは確認できなかった</li>
</ul>
<h2>ストーリー6: カタール前首長ハマド氏死去</h2>
<ul>
<li>BBCとFrance24は、カタール前首長シェイク・ハマド・ビン・ハリーファ・アール・サーニ氏が74歳で死去したと報じた</li>
<li>産経は「カタール前首長のハマド氏死去、74歳」として記事を掲載し、1995年の無血宮廷クーデターでの就任にも触れた</li>
<li>NHK・朝日・毎日・読売・日経の当日取得記事には該当見出しがない。中東の要人死去でも、継続的な外交・エネルギー取材を置く媒体に扱いが限られた</li>
</ul>
<h2>まとめ</h2>
<p>今回取り上げた6件のうち、5件は日本6媒体の当日取得記事で該当見出しを確認できなかった。特にコンゴ民主共和国のエボラ治療試験、ナイジェリアの治安作戦、途上国債務と教育、南アフリカの移民送還は、保健・人権・開発・治安に直結するが、いずれもアフリカ関連という共通点を持つ。カタール前首長の死去だけは産経が取り上げた。今回の比較は、国際報道が日本との直接の利害、または大国間の軍事・経済に集中し、グローバルサウスの長期課題を拾いにくい状況を示している。</p>
