<ul>
<li>{Apple|アップル}は、{OpenAI|オープンエーアイ}が同社の企業秘密を不正に持ち出したとして提訴した</li>
<li>{Apple|アップル}側は、{OpenAI|オープンエーアイ}の元従業員を含む上層部の指示による組織的な不正行為だったと主張している</li>
<li>提訴では、{Apple|アップル}の長年の元社員が{OpenAI|オープンエーアイ}に移籍する際に機密情報を持ち出した疑いが指摘されている</li>
<li>両社は生成{AI|エーアイ}分野で今後さらに競合が激化するとみられ、人材の引き抜きや技術流出を巡る対立が表面化した形</li>
<li>訴訟の行方次第では、{AI|エーアイ}業界の人材流動性や情報管理のあり方にも影響を与える可能性がある</li>
</ul>
<h2>{Hugging Face|ハギングフェイス}{CEO|シーイーオー}が語る「オープンソース{AI|エーアイ}」の躍進</h2>
<ul>
<li>{Hugging Face|ハギングフェイス}の{CEO|シーイーオー}{Clem Delangue|クレム ドゥランゲ}氏が、オープンソース{AI|エーアイ}の重要性が「かつてなく高まっている」と語った</li>
<li>同社は{AI|エーアイ}分野における「{GitHub|ギットハブ}」的な存在に成長し、モデルやデータセットを共有できる基盤として{Fortune 500|フォーチュン ファイブハンドレッド}企業の約半数が利用している</li>
<li>{Delangue|ドゥランゲ}氏は、企業が同じパターンを繰り返してきたと指摘。まず外部の{AI|エーアイ}サービスを「借りて」試し、次第に自社でモデルを保有・運用する体制へ移行していくという</li>
<li>クローズドな大手モデルへの依存から脱却し、コストやカスタマイズ性を重視する企業が増えていることが背景にあるとみられる</li>
<li>オープンソース{AI|エーアイ}の裾野拡大は、開発者コミュニティ全体の技術革新を加速させる要因にもなっている</li>
</ul>
<h2>{SKハイニックス|エスケーハイニックス}、265億ドル調達 — 米国史上最大の外国企業{IPO|アイピーオー}</h2>
<ul>
<li>韓国の半導体大手{SKハイニックス|エスケーハイニックス}が、米国市場で265億ドル、日本円で約4兆円規模の新規株式公開を実施した</li>
<li>米国での外国企業による{IPO|アイピーオー}としては史上最大規模となり、{AI|エーアイ}向け半導体ブームを象徴する出来事となった</li>
<li>高帯域幅メモリー、{HBM|エイチビーエム}など{AI|エーアイ}向け先端メモリーの需要急拡大が、今回の巨額調達を後押しした</li>
<li>上場を受けて、{SKハイニックス|エスケーハイニックス}や{Samsung|サムスン}には米国内での新工場建設を求める声も強まっている</li>
<li>{AI|エーアイ}半導体を巡る米中対立や供給網の再編が続く中、アジア勢の存在感がウォール街でも一段と高まった形</li>
</ul>
<h2>{GPT-5.6|ジーピーティー ファイブ ポイント シックス}が{Microsoft|マイクロソフト}{Copilot|コパイロット}の「優先モデル」に — 提携継続を強調</h2>
<ul>
<li>{OpenAI|オープンエーアイ}は、新モデル「{GPT-5.6|ジーピーティー ファイブ ポイント シックス}」が{Microsoft|マイクロソフト}{Copilot 365|コパイロット スリーシックスファイブ}の「優先モデル」であり続けると発表した</li>
<li>両社の関係を巡っては、資本提携解消など「破局」を示唆する報道も出ていたが、今回の発表はそれを打ち消す形となった</li>
<li>{OpenAI|オープンエーアイ}と{Microsoft|マイクロソフト}の提携関係が今後も続くことを対外的にアピールする狙いがあるとみられる</li>
<li>企業向け生産性ツール市場では{Google|グーグル}や{Anthropic|アンソロピック}との競争も激しく、{Microsoft|マイクロソフト}との連携維持は{OpenAI|オープンエーアイ}にとって収益基盤の安定に直結する重要な要素</li>
<li>業界内では、両社の資本構造や独占契約を巡る交渉が今後も注目材料として残るとの見方が強い</li>
</ul>
<h2>新興{Subquadratic|サブクアドラティック}、{LLM|エルエルエム}のボトルネック突破を主張 — 独立検証で信憑性強まる</h2>
<ul>
<li>新興企業{Subquadratic|サブクアドラティック}は、2017年以来{LLM|エルエルエム}の課題とされてきた「アテンション機構の計算コストが入力の長さの2乗で増える」問題を解決したと主張している</li>
<li>全ての単語同士の関係を計算する従来の「密なアテンション」ではなく、必要な関係だけを動的に選ぶ「疎なアテンション」方式を採用したモデル「{SubQ|サブキュー}」を開発</li>
<li>同モデルは従来比で最大12倍の文章量を同時処理でき、大量の文書やコードベース全体を扱うような作業に強みを持つとされる</li>
<li>発表当初は、自己申告のスコアのみで第三者による検証がなく懐疑的な見方が多かった</li>
<li>その後、独立機関による評価結果が公開され、{Google DeepMind|グーグル ディープマインド}や{OpenAI|オープンエーアイ}、{Anthropic|アンソロピック}の主要モデルに匹敵する性能を確認したとの報告が出て、信憑性が高まっている</li>
</ul>
<h2>中国、世界初の侵襲型脳・コンピュータ接続用チップを承認</h2>
<ul>
<li>中国当局が、頭蓋内に埋め込む侵襲型の脳・コンピュータインターフェース、{BCI|ビーシーアイ}用チップを世界で初めて承認した</li>
<li>埋め込み型{BCI|ビーシーアイ}は、まひなどで身体を自由に動かせない患者が、脳の信号だけで機器やコンピュータを操作できるようにする技術</li>
<li>頭蓋骨の外側に装着する非侵襲型と異なり、脳内に直接電極を埋め込むため、より精密な信号読み取りが可能とされる一方、安全性の審査が厳格に求められる</li>
<li>米国でも同様の侵襲型{BCI|ビーシーアイ}の臨床試験が進んでおり、脳直結型デバイスの実用化競争が国際的に激化している</li>
<li>将来的には、麻痺患者の意思疎通支援だけでなく、{AI|エーアイ}との直接インターフェースとしての応用も議論され始めている</li>
</ul>
<h2>国連、ジュネーブで{AI|エーアイ}ガバナンス初会合 — ディープフェイクによる選挙介入に警鐘</h2>
<ul>
<li>国連は7月6日から7日にかけてスイス・ジュネーブで「{AI|エーアイ}ガバナンスに関する世界対話」の初会合を開催した</li>
<li>会合に先立って公表された独立科学者パネルの予備報告書は、{AI|エーアイ}生成のディープフェイクや偽情報が公的信頼と選挙の公正性を脅かしていると警告している</li>
<li>報告書は「{AI|エーアイ}は説得力のあるコンテンツを大規模に生成・配信することを容易にし、情報の信頼性を徐々に損なっている」と指摘し、実際に候補者を狙ったディープフェイクが選挙結果に大きな影響を与えた事例もあるとした</li>
<li>ディープフェイクの99パーセントが性的な内容であり、そのうち96パーセントが女性や少女を標的にしているとの指摘もあり、被害の深刻さが浮き彫りになった</li>
<li>各国はまだ統一的な規制の枠組みを持たず、国際的な合意形成に向けた議論が急務とされている</li>
</ul>
<h2>シドニー大学と{IBM|アイビーエム}、量子コンピュータのエラーの主要因を特定</h2>
<ul>
<li>シドニー大学と{IBM|アイビーエム}の研究チームが、156量子ビットの「{Heron|ヘロン}」プロセッサを用いた実験で、量子計算エラーの主要因の1つを特定した</li>
<li>演算の途中で測定を行う「回路途中測定」の際に生じるノイズ、「測定誘起アイドリングノイズ」が、論理量子ビットの信頼性を大きく損なっていることが判明</li>
<li>測定待ちの間にデータ量子ビットが待機する時間を圧縮するよう演算スケジュールを再設計したところ、エラー訂正1サイクルあたりの論理量子ビット生存率が90パーセント未満から96パーセント超へと大幅に改善した</li>
<li>誤り耐性を持つ実用的な量子コンピュータの実現には、こうした細かなノイズ源の特定と対策の積み重ねが不可欠とされる</li>
<li>研究成果は学術誌{Nature Communications|ネイチャー コミュニケーションズ}に掲載され、他の量子ハードウェア開発チームにも応用が期待されている</li>
</ul>
