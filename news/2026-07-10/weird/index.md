<h2>ポケモンGO10周年、タイムズスクエアに大群衆が集結してミュウツーと激突</h2>
<ul>
<li>「ポケモンGO」10周年を記念し、開発元Nianticがニューヨーク・タイムズスクエアでサプライズイベントを開催</li>
<li>2016年の初代ローンチトレーラーで描かれていた「タイムズスクエアでミュウツーと戦う」という当時は実現していなかった演出を、10年越しについに現実の路上で再現</li>
<li>大勢のプレイヤーがスマートフォン片手に現地に集結し、周辺の道路が一時騒然となるほどの熱気に</li>
<li>出典: <a href="https://www.wired.com/story/thousands-of-pokemon-go-players-descend-on-times-square-to-defeat-mewtwo/">Wired</a></li>
</ul>
<h2>ヒト型ロボット「Neo」の指がヒトの手を超えた? 秒速8メートルの俊敏さに注目</h2>
<ul>
<li>ロボット開発企業1Xが、家庭用ヒト型ロボット「Neo」の新型ハンド(手)を公開</li>
<li>指と手のひらに合計25個の関節(自由度)を搭載。ヒトの手の27自由度に迫る滑らかな動きを実現</li>
<li>動作速度は最大秒速8メートルに達し、これまで観測されたどのヒト型ロボットの手よりも俊敏と評される</li>
<li>指先には高精度の触覚センサーを内蔵し、物を握った際の「滑り」までリアルタイムで検知して握り直しが可能。IP68防水仕様で丸洗いもできるため、料理や自己清掃といった作業も想定</li>
<li>出典: <a href="https://www.wired.com/story/the-1x-neo-robot-has-freaky-fast-fingers/">Wired</a></li>
</ul>
<h2>胃の中の塊がダイエットコーラで消える? 63歳女性の意外な治療法</h2>
<ul>
<li>アメリカで、63歳の女性が上腹部の焼けるような痛みを1ヶ月ほど訴えて受診</li>
<li>原因は「胃石」。服用していた肥満治療薬(GLP-1受容体作動薬)の副作用で胃の動きが遅くなり、未消化の食物が胃の中で塊になっていた</li>
<li>医師が処方した治療法はまさかの「ダイエットコーラを飲むこと」。本来は12時間で3リットルが目安だが、炭酸が苦手な患者だったため1日1.5リットルに減量</li>
<li>治療開始から2日目に塊が「引っ張られるような感覚」とともに崩れ始め、症状は消失。医師は「手術より安全でコストも低い」方法として報告</li>
<li>出典: <a href="https://www.odditycentral.com/news/woman-drinks-diet-coke-to-dissolve-huge-mass-in-her-stomach.html">Oddity Central</a></li>
</ul>
<h2>全身トゲトゲ、見た目は完全に「エイリアン」な巨大イモムシの正体</h2>
<ul>
<li>アフリカの熱帯地域に生息する「キャベツツリーモス」の幼虫が、SNSで「まるで映画に出てくる異星生物」と話題に</li>
<li>体長は約70ミリ、直径約15ミリ。漆黒の体に白いトゲ、または赤と黄色のトゲといった派手な配色をまとう</li>
<li>見た目は凶悪そのものだが、実はトゲは「柔らかくスポンジ状」で刺さらず、人間にとっては完全に無害</li>
<li>派手な見た目は捕食者を遠ざけるための擬態で、現地では栄養価の高い食材として食べられてもいる</li>
<li>出典: <a href="https://www.odditycentral.com/animals/this-giant-spine-covered-caterpillar-looks-like-an-alien-species.html">Oddity Central</a></li>
</ul>
<h2>Amazon創業者出資の激安EVトラック、まさかの「クレヨン」コラボで塗装</h2>
<ul>
<li>ベゾス氏が出資するEVスタートアップ「Slate」が、アメリカで最も安いとされる約2万5000ドルの電動トラックにクレヨンメーカー「クレヨラ」とのコラボを発表</li>
<li>素の車体は無塗装のグレーのみが標準だが、「セルリアン」「ラズマタズ」「タンポポ色」など、クレヨラの定番5色をあしらったラッピングを約1550ドルで追加可能に</li>
<li>ラッピングを選ぶと、お揃いのクレヨラ柄キーホルダーとダッシュボードに貼る装飾パーツ「スレートレット」も付属</li>
<li>クレヨラ側にとっても自動車業界との提携は今回が初めてとのこと</li>
<li>出典: <a href="https://www.wired.com/story/slates-gray-dollar25000-truck-just-got-a-crayola-makeover/">Wired</a></li>
</ul>
