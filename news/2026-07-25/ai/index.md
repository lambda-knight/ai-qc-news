<h1>「人格」を買うAI企業とOpus 5の効率論――理研の量子HPCが交差する一日（2026年7月25日）</h1>
<p><strong>キーワード:</strong> Anthropic Opus 5 / Cognition Poke買収 / Prentis / Midjourney Co-Star / 理研ROQUO / Quantinuum Reimei</p>
<h2>オープニング：2026年7月25日 — 生成AIニュース</h2>
<ul>
<li>今日の5本を貫くのは「モデルの強さ」だけでは勝てなくなった生成AI市場だ。Anthropicは新型モデルを効率で売り込み、CognitionとMidjourneyは対話の「人柄」を丸ごと買収し、Reid Hoffman発の新興ラボはオフィスの雑務そのものを自動化しようとしている。</li>
<li>量子コンピュータの分野では、理化学研究所がGPUと量子プロセッサを直結させる基盤を稼働させ、AIと量子という2つの潮流がインフラの層で合流し始めた。</li>
</ul>
<h2>Anthropic「Opus 5」公開――効率重視という評価も</h2>
<ul>
<li>Anthropicは7月24日、最新モデル「Opus 5」を公開した。TechCrunchは、価格が従来モデル「Fable」より安く、制限も少ないため、多くの用途で選ばれやすくなると評価した。</li>
<li>一方Ars Technicaは、コーディングや開発作業で人気の高いモデル系列の更新だとしつつ、「Opus 4.5級の能力の飛躍とは言えない」と評し、今回の売りはトークン効率の改善であって性能面の大きな伸びではないと分析した。</li>
<li>争点は「安くなったこと」と「賢くなったこと」を同じ発表がどちらも指しているように見える点にある。Anthropicは普及を広げたい立場、既存の大口利用者は生の性能向上を求める立場で、評価の軸がずれている。</li>
<li>次に確認すべきは、独立系ベンチマークによるOpus 4.5との実測比較と、具体的な価格表、そして「制限が少ない」という説明が実際にどの利用規約の変更を指すのかだ。</li>
</ul>
<h2>Cognition、対話AI「Poke」を買収――コーディングAI「Devin」に人柄を移植</h2>
<ul>
<li>コーディングAIエージェント「Devin」を手がけるCognitionは7月24日、対話型AIアシスタント「Poke」を買収したと発表した。買収額は非公開だが「低い9桁ドル」規模と報じられている。</li>
<li>Pokeは The Interaction Company of California が開発し、iMessageやSMS、Telegram、WhatsApp経由で友人のように会話しながら旅行・健康・財務・予定管理・学習を手伝うサービスで、3か月で1億件超のメッセージがやり取りされた。</li>
<li>Cognitionは、Pokeの親しみやすい会話スタイルと対話モデルをDevinに取り込み、「同僚のような」感覚のコーディング支援を目指すという。AIアシスタントの相互作用の仕方が、土台のモデル性能と同じくらいの価値を持ち始めたとの見立てだ。</li>
<li>争点は、消費者向けチャット相手として育った人格が、業務用コーディングツールに移されたときに本当に役立つかという点。Pokeの既存ユーザーにとっては利用先が変わるリスクもある。次に確認すべきは、Devinへの実装の具体的な形と、Pokeの既存ユーザー・チームの処遇だ。</li>
</ul>
<h2>Midjourneyが占星術アプリ「Co-Star」を買収――画像生成の枠を超える多角化</h2>
<ul>
<li>画像・動画生成AIで知られるMidjourneyは7月24日、占星術アプリ「Co-Star」を買収したと発表した。買収額は非公開。Co-Starは月間アクティブユーザー約430万人を持ち、ユーザーが自分の出生図（アストロロジカル・バースチャート)を作成し友人と共有できるサービスで、AIと人間の両方がホロスコープや相性診断を提供している。</li>
<li>Co-Starのチームは約24人で、コンシューマー向けアプリの開発経験を持つ。Midjourneyはこれまでも医療分野やスパ事業へ進出しており、今回の買収は単独アプリの獲得を含む製品ラインの多角化路線の一環と位置づけられる。</li>
<li>争点は、画像生成モデルの競争が激しさを増す中で、こうした周辺分野への多角化が本業の競争力強化につながるのか、それとも分散に終わるのかという点。Co-Star側のユーザーには、AI画像企業の傘下に入ることへの受け止め方の違いもあり得る。</li>
<li>次に確認すべきは、Co-Starの占星術コンテンツへのAI活用が具体的にどう変わるか、そしてMidjourneyが今後も同様の消費者向けアプリ買収を続けるかどうかだ。</li>
</ul>
<h2>Prentis、評価額10億ドルで1億ドル調達へ――Reid Hoffman・Mark Pincus発のオフィス自動化AI</h2>
<ul>
<li>LinkedIn共同創業者のReid Hoffman氏とZynga創業者のMark Pincus氏が加わる新興AIラボ「Prentis」が、評価額10億ドルで1億ドルの資金調達を協議中と7月24日に報じられた。CEOはRitankar Das氏で、2026年4月に立ち上げた。</li>
<li>既に顧客契約で最大5000万ドル相当を確保済みという。事業内容は、保険金請求処理や関税払い戻しの例外処理など、オフィスワーカーの定型業務をコンピュータ操作型AIエージェントで自動化することだ。</li>
<li>自社開発モデル「Hive-32B」は、最前線級のAPIと比べて約10分の1のコストでタスクを実行できると主張しており、従業員は25人を超える。</li>
<li>争点は、この「10分の1のコスト」という主張がまだ検証段階にあること。既存のRPA(定型業務自動化)企業や大手クラウドのエージェント機能との競合も避けられない。次に確認すべきは、調達の正式クローズと、実際の顧客業務での精度・失敗率の実測データだ。</li>
</ul>
<h2>理化学研究所の量子HPC融合基盤「ROQUO」稼働――Quantinuum・Nvidiaと連携</h2>
<ul>
<li>理化学研究所は、量子コンピュータとスーパーコンピュータを組み合わせたハイブリッド基盤「ROQUO」の稼働を進めており、7月22日までの報道でその全体像が明らかになった。NVIDIAのGB200 NVL4計算ノード135基、Blackwell GPU合計540基、Grace CPU270基を搭載し、倍精度演算で19.80PFLOPSの性能を持つ。</li>
<li>ROQUOは、既存のスーパーコンピュータ「富岳」やIBMの量子コンピュータ「ibm_kobe」に加え、理研和光地区に設置されたQuantinuum社のイオントラップ型量子コンピュータ「Reimei」と、学術情報ネットワークSINET経由で直結される。目的は、分子分光など量子化学分野の応用をベンチマークし、半導体向けEUV感光剤の評価やエネルギー貯蔵材料の設計といった産業応用を加速させることだ。</li>
<li>運用では、NVIDIAのCUDA-Q基盤上で動く進化的AIの仕組みがReimei向けの量子回路を自動生成・最適化する。この取り組みは、量子コンピューティングとAI・HPCを組み合わせる「日米ジェネシス・ミッション」提携の一つの節目と位置づけられている。</li>
<li>争点は、この基盤の主役が実質的に540基のBlackwell GPUという古典計算資源であり、量子プロセッサ「Reimei」自体の量子ビット規模や性能はまだ確認しにくい点。理研・Quantinuum・NVIDIAそれぞれに「量子AI基盤の主導権を握った」と見せたい思惑がある。次に確認すべきは、Reimeiの具体的な量子ビット数と、量子化学ベンチマークの実際の計算結果だ。</li>
</ul>
<h2>今日のまとめ</h2>
<ul>
<li>CognitionとMidjourneyの買収は、モデル性能だけでなく「人柄」や「周辺アプリ」を丸ごと取り込む競争が始まったことを示した。</li>
<li>Anthropicの「Opus 5」は、値段と制限緩和で選ばれる方向と、性能面では大きな飛躍ではないという評価が同時に存在する。</li>
<li>Prentisは、オフィスの定型業務をAIエージェントに置き換える競争が、著名起業家を巻き込んで本格化していることを示している。</li>
<li>理研のROQUOは、量子コンピュータが単独で語られる段階から、GPUクラスターと組み合わされたインフラの一部として運用される段階に移りつつあることを示した。次に確認すべきは、各社の主張の裏にある実測データが出そろうかどうかだ。</li>
</ul>
