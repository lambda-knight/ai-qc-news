<h2>論文1: 一度のコンパイルで高速化する状態ベクトル量子シミュレーター</h2>
<ul>
<li>変分量子回路を何度も評価する処理では、毎回コンパイルする負担が大きい。</li>
<li>提案するシミュレーターは回路構造を一度だけコンパイルし、パラメーターだけを差し替えて反復実行する。</li>
<li>既存汎用フレームワークとの比較で、回路の反復評価が多い場面の高速化を狙う。実機の量子優位を示す研究ではない。</li>
</ul>
<h2>論文2: 光と結合するスピン量子ビットで計算とネットワークをつなぐ</h2>
<ul>
<li>スピン量子ビットは情報を保持しやすい一方、遠隔ノードを結ぶ光との接続が課題である。</li>
<li>研究は光学的なスピン量子ビットを使い、量子古典ハイブリッドの計算と通信を併せる構想を示す。</li>
<li>素子・制御・ネットワークを別々に最適化するのでなく、全体の接続性で設計する必要を論じた。</li>
</ul>
<h2>論文3: 広帯域導波路に組み込んだ固体スピン量子ビットの遠隔もつれ</h2>
<ul>
<li>離れた量子ビットをもつれさせることは、量子ネットワークの基礎となる。</li>
<li>固体中のスピン量子ビットを広帯域の導波路へ集積し、光子を介した遠隔もつれ生成を扱う。</li>
<li>量子インターネットには、単一素子の品質だけでなく、光の損失と集積製造の両方が問われる。</li>
</ul>
<h2>論文4: 量子コンピュータ上のホログラフィック符号で重力らしい振る舞いを観測</h2>
<ul>
<li>ホログラフィック符号は、境界側の量子情報から内部空間を表現する理論モデルである。</li>
<li>量子回路上で符号を実装し、重力に似た特徴量を観測したと報告する。</li>
<li>宇宙の重力を直接シミュレーションした証明ではなく、量子誤り訂正と時空の関係を実験的に探る一歩である。</li>
</ul>
<h2>論文5: 量子ニューラルネットワークへの調和的バックドア攻撃</h2>
<ul>
<li>学習済みモデルに特定入力でだけ誤動作する仕掛けを埋め込むバックドアは、量子機械学習にも起こりうる。</li>
<li>研究は量子ニューラルネットワークの表現に合わせ、通常精度を保ったまま標的動作を誘う攻撃を検討した。</li>
<li>量子AIを実用化する前に、学習データ、回路、評価環境を含むセキュリティ検査が必要になる。</li>
</ul>
